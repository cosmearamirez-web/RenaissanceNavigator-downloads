# RenaissanceNavigator / MMEP downloads

Public download location for compiled Windows x64 application releases.

**No app download is published yet.** A release will be posted only after the source-access
arrangement required by its license and third-party packaging review are complete.

The development repository, original-program references, serial captures, video, operator data
and full research backups remain private/local. Nothing here connects to an embroidery machine.

Future packages will include installation instructions, version-specific limitations, checksums
and applicable license/source information. A protocol acknowledgment does not establish physical
sew-out compatibility for every design. Never bypass an uncertain-transfer lock or automatically resend.
